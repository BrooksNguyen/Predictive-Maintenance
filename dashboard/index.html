Predictive Maintenance

An end-to-end industrial IoT pipeline designed to anticipate turbofan engine failure before it happens, saving millions in reactive maintenance costs.

The Problem

Why Predictive Maintenance?

In aerospace and industrial manufacturing, unexpected equipment failure costs lives and millions of dollars. Traditional "reactive" maintenance fixes things after they break. "Preventative" maintenance replaces parts too early, wasting money. Predictive Maintenance (PdM) uses live telemetry and machine learning to predict exactly when a component will fail, maximizing its Remaining Useful Life (RUL).

The Dataset

NASA C-MAPSS

This project is powered by the Commercial Modular Aero-Propulsion System Simulation (C-MAPSS) dataset provided by NASA. It contains run-to-failure simulated telemetry data for turbofan engines. The engine operates normally at the start of each time series, and develops a fault at some point during the series, eventually reaching failure.

Architecture

The Technology Stack

A fully containerized microservice architecture handling everything from raw socket ingestion to machine learning inference.

1. IoT Simulator (Python)

Reads the NASA dataset and streams it row-by-row over a TCP socket, perfectly mimicking a real-time hardware sensor emitting packets over a network.

2. PySpark Structured Streaming

A distributed ETL job that continuously consumes the TCP stream, applies a strict schema, and computes rolling-window statistics (mean, std) on the fly.

3. ScyllaDB (NoSQL)

Used for its ultra-fast write performance. It stores both the raw high-frequency telemetry and the processed machine learning features.

4. XGBoost ML Service

A separate inference service that evaluates the latest data against a pre-trained XGBoost Regressor to predict the remaining cycles before failure.

Deployment

How to Run Locally

Because this architecture relies on heavy distributed systems (Spark Master/Worker, ScyllaDB), the full platform cannot run directly on Vercel. You must deploy it locally using Docker Compose.

# Clone the repository
git clone https://github.com/BrooksNguyen/Predictive-Maintenance.git
cd Predictive-Maintenance
# Spin up all 7 microservices
docker-compose up --build -d
# Access the interactive dashboard
Open http://localhost:8501 in your browser
