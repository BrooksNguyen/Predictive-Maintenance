Turbofan Engine
Predictive Maintenance.

An industrial-grade IoT platform designed to ingest raw sensor telemetry, process time-series data at scale, and predict Remaining Useful Life (RUL) before catastrophic failure occurs.

Data Flow & Architecture

01

IoT Data Ingestion

Continuous TCP socket streaming of high-frequency sensor readings simulating active aircraft engines.

02

Stream Processing

PySpark ETL consumes the data stream, validates constraints, and computes rolling window features (mean, std) on the fly.

03

NoSQL Storage

Processed telemetry and features are written into ScyllaDB, optimized for massive time-series write workloads.

04

XGBoost Inference

A dedicated ML service polls the database, evaluates the degradation curve using XGBoost, and updates the dashboard.

Core Technologies

PySpark ScyllaDB XGBoost Streamlit Docker Compose
