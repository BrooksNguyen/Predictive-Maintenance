Predictive Maintenance.

An end-to-end distributed system designed to ingest, process, and predict turbofan engine failure using Spark and XGBoost.

The Problem

Averting Catastrophic Failure

In aerospace and industrial manufacturing, unexpected equipment failure costs lives and millions of dollars. Traditional "reactive" maintenance fixes things after they break. "Preventative" maintenance replaces parts too early, wasting capital. Predictive Maintenance (PdM) uses live telemetry and machine learning to predict exactly when a component will fail, maximizing its Remaining Useful Life (RUL).

The Dataset

NASA C-MAPSS FD001

This project processes the Commercial Modular Aero-Propulsion System Simulation (C-MAPSS) dataset provided by NASA. It contains run-to-failure simulated telemetry data for turbofan engines, acting as a real-world benchmark for degradation forecasting.

System Architecture

The Technology Stack

A containerized microservice architecture built for high-throughput stream processing.

01 // INGESTION

IoT Simulator (Python)

Streams C-MAPSS data row-by-row over a raw TCP socket, mimicking high-frequency hardware sensor payloads.

02 // PROCESSING

PySpark ETL

A distributed Structured Streaming job that consumes the TCP stream and computes rolling-window statistics on the fly.

03 // STORAGE

ScyllaDB (NoSQL)

Ultra-low latency wide-column store used to persist both raw telemetry packets and processed ML features.

04 // INFERENCE

XGBoost ML Service

Continuously evaluates incoming feature vectors against a pre-trained Regressor model to predict failure cycles.

Deployment Instructions

The full platform (Spark Master/Worker, ScyllaDB) requires local container orchestration. Use Docker Compose to spin up the cluster.

# Clone the repository
git clone https://github.com/BrooksNguyen/Predictive-Maintenance.git
cd Predictive-Maintenance
# Spin up all 7 microservices in detached mode
docker-compose up --build -d
# Access the interactive Streamlit dashboard
open http://localhost:8501
